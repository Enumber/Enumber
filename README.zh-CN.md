# ENum

只是一个做点小东西的 ENumber。

我做一些小工具，用来解决自己每天会遇到的问题。
大部分是给 Linux 写的，都开源了。

### 主要项目

| | 做什么 |
|---|---|
| **[vokey](https://github.com/Enumber/vokey)** | 按住热键说话，离线的中文语音输入（Linux/X11）。文字直接落进光标所在的窗口。不联网，不用账号。 |
| **[flipscan](https://github.com/Enumber/flipscan)** | 高拍仪对着书，翻一页自动拍一页，再把照片处理成清晰的扫描件。 |
| **[dropdesk](https://github.com/Enumber/dropdesk)** | 把已安装的应用重新放回 GNOME 桌面——补回 GNOME 删掉的功能。快捷方式已经授信，不会弹「是否允许启动」。 |
| **[BeeBEEP（改版）](https://github.com/Enumber/BeeBEEP)** | 无服务器局域网聊天工具的界面改版——在局域网内聊天、传文件，不需要服务器也不需要联网。沿用上游的 GPL-3。 |

---

### 它们的共同点

- **不用 sudo** —— `bash install.sh` 会建好本地虚拟环境，并在桌面和应用菜单各放一个启动图标。不主动要求就不动系统目录。
- **中英双语** —— README 和界面都是。
- **离线可用** —— 不用注册，不上传数据，不联网回传。
